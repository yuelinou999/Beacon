Beacon · MediaPipe Spike

Day-2 feasibility compare against the Day-1 WebLLM spike. MediaPipe LLM Inference is Google's official Gemma web/on-device runtime (docs) — for a Gemma hackathon track, this could be the more credible final integration path. This page mirrors the WebLLM spike's measurement shape so the two runtimes can be compared 1:1.

Operator note — model acquisition is harder than WebLLM: Unlike WebLLM (one-line model_id selection from a prebuilt registry), MediaPipe expects YOU to provide a .litertlm file URL via modelAssetPath. Sources: HuggingFace litert-community (Google-curated Gemma web variants) or your own self-hosted file. For L2 offline, the model file MUST be on a localhost origin (python3 -m http.server 8080 from a directory containing the .litertlm) or already cached by the browser.

Known risk: Gemma 4 E2B web is reported to crash with "memory access out of bounds" on Chrome 146 / Apple M4 (issue #6270). This spike sticks to Gemma 3 1B (Plan A) and Gemma 2 2B (Plan B) — both reported stable.
